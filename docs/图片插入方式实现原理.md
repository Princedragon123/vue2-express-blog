# 三种图片插入方式实现原理

## 1️⃣ 点击工具栏图片按钮（最基础）

**实现位置**：`src/vue/components/create/QuillEditorWrapper.vue`

**实现方式**：
- 在Quill初始化时，通过`handlers.image`自定义图片按钮的点击事件
- 隐藏的`<input type="file">`用于选择文件

**流程**：
```
点击工具栏图片按钮 → handleQuillImageUpload() → 触发隐藏的input.click()
→ 用户选择文件 → 触发change事件 → handleContentImageUpload(event)
→ 获取file对象 → FormData封装 → POST /api/blogs/upload-image
→ 拿到URL → quillEditor.insertEmbed(range.index, 'image', url) 插入到光标位置
```

**关键代码**：
```javascript
// Quill初始化时自定义image按钮行为
handlers: {
  'image': this.handleQuillImageUpload  // 覆盖默认的弹窗行为
}

handleQuillImageUpload() {
  this.$refs.contentImageInput.click();  // 触发文件选择
}

handleContentImageUpload(event) {
  const file = event.target.files[0];
  if (file) {
    this.uploadImage(file);  // 统一上传方法
  }
}
```

## 2️⃣ 拖拽图片到编辑器

**实现位置**：`src/vue/components/create/QuillEditorWrapper.vue`

**实现方式**：
- 监听编辑器容器的三个拖拽事件：`dragover`、`dragleave`、`drop`

**流程**：
```
用户拖拽图片进入编辑器 → dragover事件（显示拖拽提示样式）
→ 松开鼠标 → drop事件 → 从event.dataTransfer.files获取文件
→ 过滤出图片类型文件 → uploadImage(file) 上传
→ 拿到URL → insertEmbed插入图片
```

**关键代码**：
```html
<div 
  ref="quillEditorContainer" 
  class="quill-editor"
  @dragover.prevent="handleDragOver"
  @dragleave.prevent="handleDragLeave"
  @drop.prevent="handleDrop"
></div>
```

```javascript
handleDrop(event) {
  const files = event.dataTransfer.files;
  if (files && files.length > 0) {
    const imageFile = Array.from(files).find(
      file => file.type.startsWith('image/')
    );
    if (imageFile) {
      this.uploadImage(imageFile);
    }
  }
}
```

## 3️⃣ 粘贴图片（截图直接粘贴）

**实现位置**：`src/vue/components/create/QuillEditorWrapper.vue`

**实现方式**：
- 监听编辑器的`paste`事件，检查剪贴板内容

**流程**：
```
用户Ctrl+V粘贴 → paste事件触发
→ 检查event.clipboardData.items是否有图片内容
→ 有图片 → event.preventDefault()拦截默认粘贴行为
→ item.getAsFile()获取图片文件 → uploadImage上传
→ 拿到URL → insertEmbed插入图片
```

**关键代码**：
```javascript
// 在initQuillEditor中添加监听
this.quillEditor.root.addEventListener('paste', this.handlePaste);

handlePaste(event) {
  const items = event.clipboardData?.items;
  if (!items) return;
  
  for (let i = 0; i < items.length; i++) {
    const item = items[i];
    if (item.type.startsWith('image/')) {
      event.preventDefault();  // 拦截默认行为
      const file = item.getAsFile();
      if (file) {
        this.uploadImage(file);
      }
      break;
    }
  }
}
```

## 统一上传方法

所有三种方式最终都调用同一个`uploadImage()`方法：

```javascript
uploadImage(file) {
  const formData = new FormData();
  formData.append('image', file);
  
  this.$emit('uploading', true);
  
  this.$http.post('/api/blogs/upload-image', formData)
    .then(data => {
      if (data.success) {
        const range = this.quillEditor.getSelection(true);
        this.quillEditor.insertEmbed(range.index, 'image', data.data.url);
        this.quillEditor.setSelection(range.index + 1);
        this.$emit('notify', '图片插入成功！', 'success');
      } else {
        this.$emit('notify', `图片上传失败: ${data.message}`, 'error');
      }
    })
    .catch(() => {
      this.$emit('notify', '上传图片失败，请稍后重试', 'error');
    })
    .finally(() => {
      this.$emit('uploading', false);
      this.$refs.contentImageInput.value = '';  // 清空input
    });
}
```

## 后端处理

**接口**：`POST /api/blogs/upload-image`
**中间件**：Multer处理multipart/form-data格式的文件

**流程**：
```
接收FormData → Multer解析出文件 → 存储到uploads目录
→ 返回文件路径URL给前端 → 前端用insertEmbed插入编辑器
```
